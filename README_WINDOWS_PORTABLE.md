# Portable Windows — 1.8.0

Ikuti [MULAI_DI_SINI.md](MULAI_DI_SINI.md). Workflow: **Build Windows Portable EXE**. Artifact: `MediaForge-Studio-Windows-Portable`. Target keluaran: `MediaForge-Studio-Portable-1.8.0-Windows-x64.exe`.

Paket membawa Electron, engine browser, FFmpeg/FFprobe, yt-dlp, VCDImager/DLL, CDRDAO, dan helper IMAPI. Source ZIP bukan executable final. Portable tidak memakai updater NSIS; unduh versi portable berikutnya secara terpisah. Pengujian Windows dan perangkat burner tetap diperlukan; lihat [PERBAIKAN_1.8.0.md](PERBAIKAN_1.8.0.md).
